# FoodieVibe System Overview

FoodieVibe is a cross-cultural food discovery platform designed to connect students through recipes, food stories, and cultural experiences.

---

## Core User Flow

User
↓
Landing Page
↓
Recipe Discovery
↓
Community Interaction
↓
Cultural Stories
↓
Profile Experience

---

## Technology Stack

### Frontend

- React
- TypeScript
- Vite
- Tailwind CSS

### Mobile Platform

- Capacitor
- Android
- iOS

### Version Control

- Git
- GitHub

---

## Design Principles

- Mobile-first design
- Cross-cultural accessibility
- Simple user navigation
- Responsive user experience
- Community-focused interaction

## Deployment

The project was developed as a hackathon prototype and supports deployment to both web and mobile platforms through Capacitor.
